Множини та операції над ними

мова, якою математика описує «групи» чого завгодно

Що таке множина

Множина — це сукупність об'єктів, об'єднаних за якоюсь ознакою: множина учнів класу, множина цифр, множина коренів рівняння. Об'єкти, з яких складається множина, називають її елементами. Множини позначають великими латинськими літерами: A, B, N.

Позначення
  • a ∈ A — «a належить множині A» (a — її елемент). a ∉ A — «не належить».
  • ∅ — порожня множина, у ній немає жодного елемента. Наприклад, множина коренів рівняння x² = −1.
  • Множини бувають скінченні (цифри: 10 елементів) і нескінченні (натуральні числа N).

Як задати множину

Два способи
  • Переліком елементів у фігурних дужках: A = {1, 3, 5, 7}. Порядок не важливий, і кожен елемент записують один раз.
  • Характеристичною властивістю — правилом, яке мають усі елементи і тільки вони: «A — множина непарних одноцифрових чисел». Так можна задати навіть нескінченну множину.

Рівні множини. Підмножина

Множини рівні (A = B), якщо складаються з тих самих елементів: {1, 2, 3} = {3, 1, 2}. Якщо кожен елемент множини B належить і множині A, то B — підмножина A: B ⊂ A. Наприклад, {2, 4} ⊂ {1, 2, 3, 4}. Порожня множина — підмножина будь-якої множини, а кожна множина — підмножина самої себе.

Числові множини вкладені одна в одну: N ⊂ Z ⊂ Q ⊂ R — кожне натуральне число ціле, кожне ціле — раціональне, кожне раціональне — дійсне. (Про дійсні числа — у розділі IV.)

Перетин і об'єднання

Множини наочно зображують кругами — діаграмами Ейлера–Венна. Візьмемо A = {1, 2, 3, 4} і B = {3, 4, 5, 6}:

Операції над множинами
  • Перетин A ∩ B — елементи, що належать і A, і B: {3, 4}.
  • Об'єднання A ∪ B — елементи, що належать хоча б одній з множин: {1, 2, 3, 4, 5, 6}. Спільні елементи записують один раз!
  • Різниця A \ B — елементи A, яких немає в B: {1, 2}.

∩ — «і» (спільне), ∪ — «або» (усе разом)

Нехай A — множина дільників числа 12: {1, 2, 3, 4, 6, 12}, B — множина дільників 18: {1, 2, 3, 6, 9, 18}. Тоді A ∩ B = {1, 2, 3, 6} — це спільні дільники, а найбільший з них, 6, — НСД(12; 18). Ось де ти вже користувався перетином множин!

Задачі на кількість елементів

Якщо просто додати кількості елементів A і B, спільні елементи порахуються двічі. Тому один раз їх треба відняти:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
n(A) — кількість елементів множини A
Задача

У класі 28 учнів. 16 з них ходять на футбол, 10 — на шахи, а 4 — і туди, і туди. Скільки учнів не ходять на жоден гурток?

Ф — футболісти, Ш — шахісти. n(Ф) = 16, n(Ш) = 10, n(Ф ∩ Ш) = 4.

Хоча б на один гурток ходять: n(Ф ∪ Ш) = 16 + 10 − 4 = 22 учні.

Не ходять на жоден: 28 − 22 = 6.

Раціональні дроби

звичайні дроби, тільки з буквами

Що таке раціональний дріб

У 7 класі ми працювали з цілими виразами — там можна додавати, віднімати, множити й підносити до степеня, але не ділити на змінну. Тепер з'являється ділення. Вираз виду A/B, де A і B — многочлени, називають раціональним дробом: наприклад, (x + 1)/(x − 3) або 5/a².

Цілі й дробові вирази разом називають раціональними виразами. Головна нова думка розділу — на нуль ділити не можна. Тому в кожного дробу є «заборонені» значення змінної.

Область допустимих значень (ОДЗ)
  • ОДЗ — усі значення змінних, при яких вираз має зміст.
  • Для дробу A/B шукаємо, коли знаменник B = 0, — ці значення й виключаємо.
  • Цілий вираз має зміст при будь-яких значеннях змінних.

Знайдемо ОДЗ дробу (x + 2)/(x² − 9). Знаменник x² − 9 = (x − 3)(x + 3) дорівнює нулю при x = 3 і x = −3. Отже, ОДЗ: усі числа, крім 3 і −3. А от чисельник на ОДЗ не впливає: при x = −2 дріб просто дорівнює нулю.

Основна властивість дробу. Скорочення

Як і зі звичайними дробами (2/4 = 1/2), чисельник і знаменник можна помножити або поділити на той самий ненульовий вираз — значення дробу не зміниться.

A/B = (A·C)/(B·C)
C ≠ 0; читаємо зліва направо — зведення, справа наліво — скорочення
Як скоротити дріб
  • 1. Розклади чисельник і знаменник на множники (спільний множник, формули скороченого множення, групування — усе з 7 класу).
  • 2. Поділи чисельник і знаменник на спільний множник.

скорочують множники, а не доданки: у (x + 3)/3 трійки скоротити не можна!

Скоротимо (x² − 4)/(x² + 2x). Чисельник — різниця квадратів: (x − 2)(x + 2). Знаменник — спільний множник: x(x + 2). Скорочуємо на (x + 2): (x − 2)/x.

Корисний трюк зі знаком: (a − b) = −(b − a). Тому (3 − x)/(x − 3) = −(x − 3)/(x − 3) = −1.

Додавання й віднімання дробів

З однаковими знаменниками все просто: додаємо (віднімаємо) чисельники, знаменник лишаємо. З різними — спершу зводимо до спільного знаменника, як 1/2 + 1/3 = 3/6 + 2/6.

a/c ± b/c = (a ± b)/c
a/b + c/d = (ad + cb)/(bd)

Обчислимо 3/x − 2/(x + 1). Спільний знаменник x(x + 1). Додаткові множники: (x + 1) для першого дробу, x — для другого. Маємо: (3(x + 1) − 2x)/(x(x + 1)) = (3x + 3 − 2x)/(x(x + 1)) = (x + 3)/(x(x + 1)).

Розклад допомагає знайти найменший спільний знаменник: 1/(x − 2) + 4/(x² − 4). Оскільки x² − 4 = (x − 2)(x + 2), спільний знаменник — саме (x − 2)(x + 2): (x + 2 + 4)/((x − 2)(x + 2)) = (x + 6)/(x² − 4).

Множення, ділення й піднесення до степеня

Тут навіть простіше, ніж з додаванням — спільний знаменник не потрібен.

Три правила
  • Множення: a/b · c/d = (ac)/(bd) — чисельник на чисельник, знаменник на знаменник.
  • Ділення: a/b : c/d = a/b · d/c — множимо на перевернутий дріб.
  • Степінь: (a/b)ⁿ = aⁿ/bⁿ.

до множення — розклади на множники, після — скороти

Обчислимо (x² − 1)/(3x) : (x + 1)/(6x²). Перевертаємо другий дріб і множимо: (x − 1)(x + 1)/(3x) · 6x²/(x + 1). Скорочуємо (x + 1) та 3x: 2x(x − 1).

цікавинка · де це в житті

Камера твого телефона фокусується за формулою лінзи 1/F = 1/d + 1/f — це сума раціональних дробів: d — відстань до обʼєкта, f — до матриці. Коли ти наводиш камеру на щось ближче, автофокус зсуває лінзу саме так, щоб рівність виконувалась. Та сама математика в задачах «на спільну роботу»: якщо один принтер друкує партію за a годин, а другий за b, то разом — за ab/(a + b) годин. А формула для паралельно зʼєднаних резисторів, з якою зустрінешся на фізиці цього року, виглядає точнісінько так само.

Рівняння, степені та гіпербола

коли змінна опиняється в знаменнику

Раціональні рівняння

Раціональне рівняння — рівняння, обидві частини якого — раціональні вирази. Якщо змінна є в знаменнику, рівняння дробове, і тут чатує нова пастка — сторонні корені: значення, які ми знайшли, але при яких знаменник перетворюється на нуль.

A / B = 0  ⇔  A = 0 і B ≠ 0
дріб дорівнює нулю, коли нулю дорівнює чисельник, а знаменник — ні
Як розв'язати дробове рівняння
  • 1. Знайди ОДЗ: які x роблять знаменники нулем?
  • 2. Перенеси все в один бік і зведи до одного дробу A/B = 0 — або помнож обидві частини на спільний знаменник.
  • 3. Розв'яжи рівняння A = 0.
  • 4. Відкинь корені, що не входять в ОДЗ.

(x² − 4)/(x − 2) = 0. Чисельник: x² − 4 = 0 → x = 2 або x = −2. Але при x = 2 знаменник дорівнює нулю — це сторонній корінь. Відповідь: x = −2.

3/x = 6/(x + 2). ОДЗ: x ≠ 0, x ≠ −2. За основною властивістю пропорції: 3(x + 2) = 6x → 3x + 6 = 6x → x = 2. Число 2 в ОДЗ входить, тож відповідь: x = 2.

Степінь з цілим від'ємним показником

Пригадай: при діленні степенів показники віднімаються, a⁵ : a³ = a². А що буде, якщо поділити a³ : a⁵? З одного боку, це a³⁻⁵ = a⁻². З іншого — (a·a·a)/(a·a·a·a·a) = 1/a². Отже, природно домовитися:

a⁻ⁿ = 1 / aⁿ,   a⁰ = 1
a ≠ 0, n — натуральне число

Найкраще в цьому означенні те, що усі п'ять властивостей степеня з 7 класу працюють і для від'ємних показників: aˣ·aʸ = aˣ⁺ʸ, (aˣ)ʸ = aˣʸ і так далі.

2⁻³ = 1/2³ = 1/8 (а не −8 і не −6!). (2/3)⁻² = (3/2)² = 9/4 — від'ємний показник «перевертає» дріб. А a⁻⁴ · a⁶ : a³ = a⁻⁴⁺⁶⁻³ = a⁻¹ = 1/a.

Стандартний вигляд числа

Дуже великі й дуже малі числа зручно записувати як a · 10ⁿ, де 1 ≤ a < 10, а n — ціле число (його називають порядком числа).

Як записати число в стандартному вигляді
  • Переносимо кому так, щоб перед нею стояла одна ненульова цифра.
  • Рахуємо, на скільки знаків перенесли: вліво — n додатне, вправо — n від'ємне.

Відстань від Землі до Сонця ≈ 150 000 000 км = 1,5 · 10⁸ км. Діаметр еритроцита ≈ 0,0000075 м = 7,5 · 10⁻⁶ м. Зверни увагу: 15 · 10⁷ — правильна рівність, але не стандартний вигляд, бо 15 > 10.

Функція y = k/x та її графік

Якщо одна величина зростає в кілька разів, а інша в стільки ж разів зменшується — це обернена пропорційність: y = k/x, k ≠ 0. Наприклад, швидкість і час на одному маршруті: t = s/v. Графік такої функції — гіпербола.

Властивості гіперболи y = k/x
  • x ≠ 0 і y ≠ 0 — графік ніколи не перетинає осей, лише необмежено до них наближається.
  • k > 0 — гілки в I і III чвертях, функція спадає на кожній гілці.
  • k < 0 — гілки в II і IV чвертях, функція зростає на кожній гілці.
  • Для будь-якої точки графіка x · y = k — так легко знайти k за однією точкою.

Гіпербола проходить через точку (2; −3). Тоді k = 2 · (−3) = −6, функція y = −6/x, гілки — у II і IV чвертях. Чи належить їй точка (−1; 6)? Перевіряємо: −6/(−1) = 6 ✓ — так.

цікавинка · де це в житті

Стандартний вигляд — мова сучасних технологій. Транзистори в нових процесорах мають розмір порядку 10⁻⁹ м (нанометри), а їх у чипі смартфона — близько 2 · 10¹⁰. Обсяг даних, які людство створює за рік, вимірюють у зетабайтах — це 10²¹ байтів. А гіпербола ховається там, де «більше одного — менше іншого»: що більше пікселів на тому самому екрані, то менший кожен піксель; що більше людей ділять піцу, то менший шматок; що вища швидкість інтернету, то коротше завантаження файлу.

розділ IV

Квадратні корені. Дійсні числа

дія, обернена до піднесення в квадрат

Функція y = x²

Почнімо з функції y = x². Її графік — парабола з вершиною в точці (0; 0), гілки напрямлені вгору. Вона симетрична відносно осі Oy, бо (−3)² = 3² = 9. Значення y ніколи не бувають від'ємними.

Арифметичний квадратний корінь

Піднести в квадрат легко: 7² = 49. А обернена задача — «яке число в квадраті дає 49?» — веде до кореня. Таких чисел два: 7 і −7. Щоб відповідь була однозначною, домовились брати невід'ємне.

√a = b  ⇔  b ≥ 0 і b² = a
вираз √a має зміст лише при a ≥ 0; (√a)² = a

√49 = 7, √0,09 = 0,3, √(1/16) = 1/4, √0 = 0. А √(−4) не існує: жодне число в квадраті не дає від'ємного.

Рівняння x² = a

А от рівняння x² = 49 має два корені: x = 7 і x = −7. Корінь — завжди одне невід'ємне число, а рівняння шукає всі числа.

Скільки коренів має x² = a
  • a > 0 — два корені: x = √a і x = −√a.
  • a = 0 — один корінь: x = 0.
  • a < 0 — коренів немає.

Раціональні, ірраціональні, дійсні числа

Корінь далеко не завжди «добувається»: √2 = 1,41421356… — десяткових знаків нескінченно багато, і вони ніколи не повторюються періодом. Таке число не можна записати дробом m/n — воно ірраціональне.

Числові множини
  • N — натуральні: 1, 2, 3, …
  • Z — цілі: …, −2, −1, 0, 1, 2, …
  • Q — раціональні: дроби m/n; у десятковому записі — скінченні або нескінченні періодичні (1/3 = 0,(3)).
  • Ірраціональні — нескінченні неперіодичні: √2, √5, π.
  • R — дійсні: усі раціональні та ірраціональні разом. N ⊂ Z ⊂ Q ⊂ R.

Властивості квадратних коренів

Чотири властивості
  • √(ab) = √a · √b (a ≥ 0, b ≥ 0) — корінь з добутку.
  • √(a/b) = √a / √b (a ≥ 0, b > 0) — корінь з частки.
  • √(a²) = |a| — корінь з квадрата дає модуль.
  • √(a²ⁿ) = |aⁿ| — наприклад, √(x⁶) = |x³|.

√(a + b) ≠ √a + √b: √(9 + 16) = 5, а √9 + √16 = 7

Обчислимо √(16 · 0,25) = √16 · √0,25 = 4 · 0,5 = 2. А √2 · √18 = √36 = 6 — властивість працює і в зворотний бік.

Перетворення виразів з коренями

Три головні прийоми
  • Винесення множника з-під кореня: шукаємо в підкореневому виразі повний квадрат. √50 = √(25 · 2) = 5√2.
  • Внесення множника під корінь: 3√2 = √(9 · 2) = √18. Так зручно порівнювати корені.
  • Звільнення від ірраціональності в знаменнику: множимо чисельник і знаменник на корінь (або на «спряжений» вираз).

Що більше: 2√7 чи 3√3? Вносимо під корінь: 2√7 = √28, 3√3 = √27. Оскільки 28 > 27, то 2√7 > 3√3.

6/√3 = 6√3/(√3 · √3) = 6√3/3 = 2√3. Для різниці коренів у знаменнику використовуємо різницю квадратів: 2/(√5 − √3) = 2(√5 + √3)/(5 − 3) = √5 + √3.

Функція y = √x

Графік y = √x — це половина параболи, «покладена на бік» (на малюнку вище — фіолетова крива). Функція визначена лише при x ≥ 0, набуває лише невід'ємних значень і зростає: що більше x, то більше √x. Точки для побудови: (0; 0), (1; 1), (4; 2), (9; 3).

Це не випадковість: тільки з таким відношенням, склавши аркуш навпіл, отримуєш аркуш А5 тієї самої форми — тож фото й документи масштабуються без обрізання. Діагональ екрана телефона чи телевізора «в дюймах» рахують через корінь — за теоремою Піфагора, яку цього року вивчаєте на геометрії. Квадратні рівняння

головне рівняння шкільної алгебри

Що таке квадратне рівняння

Квадратне рівняння — це рівняння виду ax² + bx + c = 0, де x — змінна, a, b, c — числа, причому a ≠ 0 (інакше x² зникне і рівняння стане лінійним). a — перший (старший) коефіцієнт, b — другий, c — вільний член. Якщо a = 1, рівняння називають зведеним: x² + px + q = 0.

Неповні квадратні рівняння

Якщо b або c дорівнює нулю, рівняння неповне, і розв'язується воно без жодних формул:

Три види неповних рівнянь
  • c = 0: ax² + bx = 0 → x(ax + b) = 0 → x = 0 або x = −b/a. Завжди два корені.
  • b = 0: ax² + c = 0 → x² = −c/a. Два корені, якщо −c/a > 0, інакше — жодного.
  • b = c = 0: ax² = 0 → x = 0.

ніколи не діли обидві частини на x — загубиш корінь 0

3x² − 12x = 0 → 3x(x − 4) = 0 → x = 0 або x = 4.   2x² − 18 = 0 → x² = 9 → x = ±3.   x² + 5 = 0 → x² = −5 → коренів немає.

Дискримінант і формула коренів

Для повного рівняння виділимо повний квадрат (цей прийом знаєш з 7 класу) — і отримаємо універсальну формулу. Ключову роль у ній відіграє вираз під коренем — дискримінант (від латинського «той, що розрізняє»): він розрізняє, скільки коренів має рівняння.

D = b² − 4ac,    x = (−b ± √D) / 2a
спочатку рахуємо D, потім за знаком D — корені
Три випадки
  • D > 0 — два різні корені x₁,₂ = (−b ± √D)/2a.
  • D = 0 — один корінь x = −b/2a (кажуть ще «два однакові»).
  • D < 0 — дійсних коренів немає.

корені рівняння — це точки, де парабола y = ax² + bx + c перетинає вісь Ox

2x² + 3x − 2 = 0. Тут a = 2, b = 3, c = −2. D = 3² − 4·2·(−2) = 9 + 16 = 25, √D = 5. x₁ = (−3 + 5)/4 = 1/2, x₂ = (−3 − 5)/4 = −2.

x² − 6x + 9 = 0: D = 36 − 36 = 0 → x = 6/2 = 3 (це ж (x − 3)² = 0!).   x² + x + 5 = 0: D = 1 − 20 = −19 < 0 → коренів немає.

Теорема Вієта

Французький математик Франсуа Вієт помітив дивовижний зв'язок між коренями і коефіцієнтами. Для зведеного рівняння:

x₁ + x₂ = −p,    x₁ · x₂ = q
для x² + px + q = 0; для ax² + bx + c = 0: x₁ + x₂ = −b/a, x₁·x₂ = c/a

Працює й обернена теорема: якщо числа m і n такі, що m + n = −p і m·n = q, то вони — корені рівняння x² + px + q = 0. Тож зведені рівняння з «гарними» коренями часто розв'язують усно — підбором.

x² − 7x + 12 = 0. Шукаємо два числа: добуток 12, сума 7. Це 3 і 4. Перевірка: 3 + 4 = 7 ✓, 3 · 4 = 12 ✓.   x² + 2x − 15 = 0: добуток −15 (знаки різні), сума −2 → 3 і −5.

цікавинка · де це в житті

Коли в комп'ютерній грі ти бачиш реалістичні відблиски й тіні — це трасування променів (ray tracing). Відеокарта мільйони разів на секунду перевіряє: чи влучає промінь світла в об'єкт? Для кулі ця перевірка — квадратне рівняння, а відповідь дає саме дискримінант: D > 0 — промінь пронизує кулю, D = 0 — дотикається, D < 0 — пролітає повз. Так само квадратні рівняння рахують траєкторію м'яча, стрибка чи ракети: висота польоту — це парабола, а момент приземлення — її корінь.

Квадратний тричлен і задачі

Квадратний тричлен

Квадратний тричлен — многочлен виду ax² + bx + c, a ≠ 0. Його корені — корені рівняння ax² + bx + c = 0. Якщо корені є, тричлен завжди можна розкласти на множники — це надзвичайно корисно для скорочення дробів.

ax² + bx + c = a(x − x₁)(x − x₂)
x₁, x₂ — корені тричлена; якщо D < 0, тричлен на множники не розкладається

Розкладемо 2x² − 5x + 2. D = 25 − 16 = 9, x₁ = (5 + 3)/4 = 2, x₂ = (5 − 3)/4 = 1/2. Отже, 2x² − 5x + 2 = 2(x − 2)(x − 1/2) = (x − 2)(2x − 1) — двійку внесли в другу дужку.

Скоротимо дріб (x² − 5x + 6)/(x − 2). Корені чисельника 2 і 3 (за Вієтом), тож x² − 5x + 6 = (x − 2)(x − 3). Скорочуємо: x − 3.

Біквадратні рівняння

Рівняння виду ax⁴ + bx² + c = 0 називають біквадратним. Зверни увагу: x⁴ = (x²)². Тому заміна t = x² перетворює його на звичайне квадратне.

x⁴ − 5x² + 4 = 0. Нехай t = x², t ≥ 0. Маємо t² − 5t + 4 = 0, звідки t = 1 або t = 4 (Вієт). Повертаємось: x² = 1 → x = ±1; x² = 4 → x = ±2. Відповідь: −2, −1, 1, 2.

якщо t вийшло від'ємним — відкидаємо: x² не буває від'ємним

Дробові рівняння, що зводяться до квадратних

Схема та сама, що й у розділі III: ОДЗ → множимо на спільний знаменник → розв'язуємо (тепер уже квадратне рівняння) → відкидаємо сторонні корені.

1/(x − 1) + 2/(x + 1) = 1. ОДЗ: x ≠ ±1. Множимо на (x − 1)(x + 1): (x + 1) + 2(x − 1) = x² − 1 → 3x − 1 = x² − 1 → x² − 3x = 0 → x = 0 або x = 3. Обидва в ОДЗ. Відповідь: 0; 3.

Задача

Площа прямокутника 60 см², одна його сторона на 4 см довша за іншу. Знайди сторони прямокутника.

Нехай коротша сторона x см, тоді довша — x + 4 см.

Площа: x(x + 4) = 60 → x² + 4x − 60 = 0.

D = 16 + 240 = 256, √D = 16. x₁ = (−4 + 16)/2 = 6, x₂ = (−4 − 16)/2 = −10.

Сторона не може бути від'ємною, тож −10 відкидаємо. x = 6, x + 4 = 10. Перевірка: 6 · 10 = 60 ✓.
